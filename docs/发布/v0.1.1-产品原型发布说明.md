# 太一 v0.1.1 产品原型发布说明

`v0.1.1` 是太一首个本地交互式产品原型版本。它在已经完成的命令行身份演化闭环上，
增加浏览器中的步骤引导、来源下钻、世界线比较、人工归一、快照历史、回滚和重生体验。

## 重要边界

本版本按维护者决定，在没有真实用户验证的情况下作为 Alpha 原型发布。已有三轮角色模拟
只用于发现待验证假设，不能代表真实用户反馈、市场验证或已经确认的产品缺陷。

本版本不是生产级产品、稳定公共协议或经过外部验证的研究基准，也不声称创造、检测或
证明 AI 主观意识。产品所称的身份是经过人工治理、可以被后续运行实例继承的身份状态。

## 主要变化

- 新增只监听 `127.0.0.1` 的本地交互式产品原型；
- 覆盖身份创建、同位体派生、经历输入、候选记忆来源和世界线比较；
- 支持五种人工归一策略、批准与应用双重操作、不可变快照和回滚；
- 区分同源比较组与从新快照派生的下一代同位体，并展示真实基础快照；
- 提供离线“未知任务的两种选择”演示预设；
- 新增探索场景矩阵、统一模拟记录格式和三轮十五次角色模拟；
- 完善产品定义、已知限制、持续迭代和会话交接文档。

## 安装与启动

下载本发布页附带的 `taiyi_ai-0.1.1-py3-none-any.whl`，使用 Python 3.11 或更高版本安装：

```bash
python -m pip install ./taiyi_ai-0.1.1-py3-none-any.whl
taiyi --data-dir .taiyi-prototype prototype
```

命令默认只监听本机回环地址并打开浏览器，使用完全离线且结果可重复的 `MockProvider`。

- 全部二十六项自动测试通过；
- 源码包和 wheel 构建通过；
- 全新 Python 3.13 虚拟环境安装 wheel 并运行 `taiyi --help` 通过；
- 全新数据目录启动产品原型，HTTP 200 和页面内容检查通过。

## 已知风险

真实用户尚未验证候选记忆的身份地位、可信度含义、悬置与拒绝、批准与应用、回滚语义
以及“重生”的工程边界是否容易理解。完整限制见[已知限制](../产品/已知限制.md)，模拟
假设见[多轮模拟记录](../产品/探索场景/2026-07-27-多轮模拟记录.md)。
