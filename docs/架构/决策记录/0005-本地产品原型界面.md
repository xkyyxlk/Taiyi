# 架构决策 0005：本地产品原型界面

- 状态：已接受
- 日期：2026-07-27
- 对应工作项：`TY-202607271741`

## 背景

命令行技术原型已经证明身份分叉、记忆来源、人工归一和快照回滚的工程闭环，但不适合
验证普通试用者能否理解对象关系和操作顺序。产品原型需要一个可视化外围适配器，同时
不能把早期界面误当成稳定公共协议或远程多用户产品。

## 决策

- 在现有 Python 进程中增加本地 HTTP 服务和静态单页界面；
- 服务只绑定 `127.0.0.1`，不接受网络监听地址配置；
- 页面操作全部调用既有 `IdentityService`、`MemoryService` 和 `MergeService`，不直接
  修改数据库记录；
- 继续使用当前 `--data-dir` 中的 SQLite 数据，不新增表、迁移或第二套状态；
- 静态页面和 JSON 操作保持同源，不启用跨域；
- 返回内容设置内容安全策略、禁止嵌入和禁止内容类型嗅探；
- 内部 JSON 只服务当前产品原型，不承诺兼容性，也不作为 SDK 或公共 API；
- 默认演示继续使用离线 `MockProvider`，真实提供器仍必须显式配置。

## 影响

产品原型能够表达步骤引导、对象层次、来源下钻和人工审核门，同时继承现有领域不变量。
由于只支持本地单操作者，当前不增加身份认证、会话管理、多用户权限、远程部署或生产级
Web 安全承诺。若未来需要远程访问，必须另建工作项并重新评估认证、授权、跨站请求、
传输加密、并发和数据隔离边界。
