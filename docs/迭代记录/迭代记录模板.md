# 迭代记录模板

> 复制本文件创建新记录。完成归档后只允许追加更正说明，不得删除或覆写原始内容。

## 基本信息

- 记录编号：`迭代-<四位数字>`
- 时间：`年-月-日 时:分及时区`
- 版本或里程碑：
- 工作项：`TY-<数字>`；没有正式工作项时说明原因
- 状态：进行中 / 已暂停 / 已完成 / 已取消
- 记录性质：会话迭代 / 工作项总结 / 历史回填

## 目标

- 描述本次迭代要解决的问题和完成边界。

## 本次完成内容

- 只记录实际完成并能由文件、提交或测试证明的内容。

## 重要决策

- 记录方案选择、放弃的替代方案及原因。
- 没有新增决策时明确写“无”。

## 验证结果

- `验证命令`：通过 / 失败 / 未执行及原因。

## 相关提交

- `完整提交哈希`：提交主题。
- 当前记录与实现处于同一提交时，写明通过本记录的文件历史定位。

## 影响范围

- 代码、数据、接口、文档、测试或流程的影响范围。

## 遗留事项

- 未完成内容、风险、阻塞和下一步；没有时明确写“无”。

## 更正说明

- 默认留空。发现历史记录错误时，只在这里追加日期、错误内容、更正内容和依据。
