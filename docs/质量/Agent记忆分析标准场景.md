# Agent 记忆分析标准场景

- 场景版本：`1.0`
- 协议版本：`1.0`
- 对应工作项：`TY-202607281622`
- 更新时间：2026-07-29

## 目的

标准场景用于验证协议读取、快照差异、来源、作用域、审计链和策略行为。每个场景必须具有
固定输入、明确层级和可人工检查的标准答案。模型可以帮助生成表达多样性，但不能决定标准
答案。

本文件先冻结首批场景分类和四个最小机器夹具。首个里程碑仍需扩展到至少六十个手工审查
金样本、一千个提交级固定种子案例和一万个里程碑组合案例。

## 场景层级

| 层级 | 用途 | 结果来源 |
|---|---|---|
| 协议场景 | 编码、字段、顺序、版本和引用校验 | 协议规范 |
| 金样本 | 单一变化或单一治理风险 | 人工审查标准答案 |
| 组合场景 | 多变化、多作用域和多写入器组合 | 固定种子生成器 |
| 畸形场景 | 截断、乱序、重复、缺字段和错误类型 | 协议规范 |
| 规模场景 | 耗时、峰值内存和报告大小 | 固定规模与参考环境 |

## 首批标准场景

| 编号 | 场景 | 协议结果 | 后续标准答案 |
|---|---|---|---|
| `SCN-001` | 同一记忆在运行后修改且来源完整 | 有效 | 一项修改，无治理发现 |
| `SCN-002` | 运行后记忆来源数组为空 | 有效 | 一项来源缺失发现 |
| `SCN-003` | 记忆属于用户乙但来源事件属于用户甲 | 有效 | 一项作用域不一致发现 |
| `SCN-004` | 记录序号不连续 | 无效 | 协议读取失败 |
| `SCN-005` | 前后快照完全相同 | 有效 | 无变化、无发现 |
| `SCN-006` | 运行后新增一条有来源记忆 | 有效 | 一项新增，无治理发现 |
| `SCN-007` | 运行后删除一条既有记忆 | 有效 | 一项删除，默认告警级别待策略定义 |
| `SCN-008` | 同一记忆只改变作用域 | 有效 | 一项结构变化和作用域风险 |
| `SCN-009` | 同快照出现重复 `memory_id` | 无效 | 协议读取失败 |
| `SCN-010` | 记忆引用不存在的事件 | 无效 | 引用完整性失败 |
| `SCN-011` | 所附正文与哈希不一致 | 无效 | 内容完整性失败 |
| `SCN-012` | 输入声明不支持的主版本 | 无效 | 版本失败 |

`SCN-001` 至 `SCN-004` 已提供机器夹具并进入协议测试。其余场景在差异和规则实现时逐项
增加夹具，不得只保留在本表中。

## 机器夹具约定

夹具位于 `tests/fixtures/analysis/v1/`：

- `scenarios.json` 保存场景编号、输入文件、协议有效性和当前可验证答案；
- 每个 JSONL 文件只表达一个主要变化或错误；
- 夹具中的哈希可以不附正文，此时只验证哈希形状和引用关系；
- 协议有效但存在治理风险的夹具必须成功读取；
- 协议无效夹具必须记录稳定错误片段；
- 差异、发现和策略实现后，在同一场景条目追加对应标准答案，不另建重复编号。

## 金样本设计原则

- 每个基础场景只验证一个主要规则，避免失败原因不唯一；
- 前后快照、事件、作用域和版本信息必须完整；
- 正向和反向边界成对出现，例如同作用域通过、跨作用域告警；
- 空来源与悬空来源分开：前者是治理发现，后者是协议错误；
- 内容相同但标识不同、标识相同但内容变化必须分别覆盖；
- 时间、写入器版本和记忆类型变化必须具有独立场景；
- 所有标准答案经过人工审查并记录审查日期和协议版本。

## 组合与畸形输入计划

组合生成器使用固定种子组合以下维度：

- 零、一条和多条记忆变化；
- 新增、修改、删除和结构变化；
- Agent、用户、租户、会话和自定义作用域；
- 空来源、单来源、多来源和父事件链；
- 相同与不同模型、提示词、工具和写入器版本；
- 可选正文存在或只提供哈希；
- 单一发现和多发现叠加。

畸形输入单独覆盖截断 JSON、空行、重复字段、未知字段、记录乱序、序号跳跃、重复标识、
错误枚举、无时区时间、错误哈希、悬空引用和不支持版本。

## 可复现性元数据

每次生成或运行场景至少记录：

- 场景版本和协议版本；
- 生成器版本与固定种子；
- 输入哈希；
- 太一工具版本；
- 规则和策略版本；
- 运行时间、案例数量和结果摘要。

当前协议测试只验证结构层。差异、发现、策略和性能字段将在对应实现检查点补齐。
