## 目的与口径

本基线记录固定规模输入在单一参考环境中的本地观测值，用于下一检查点冻结绝对预算和后续
回归比较。它不是跨机器性能承诺，也不证明真实项目采用价值。

每个样本由独立进程运行以下阶段：

1. 生成固定 JSONL 输入；
2. 完成协议解析、快照差异和确定性规则分析；
3. 渲染 JSON 报告。

`total_seconds` 包含以上三个阶段。`peak_traced_memory_bytes` 从输入生成前启动 Python
`tracemalloc`，覆盖生成、分析和报告渲染产生的 Python 分配峰值，但不等同于操作系统观察
到的进程常驻集。输入只携带哈希和最小协议字段，不包含正文。

## 复现方法

```text
taiyi analyze benchmark --event-count 1000 --memory-change-count 100
taiyi analyze benchmark --event-count 10000 --memory-change-count 1000
taiyi analyze benchmark --event-count 100000 --memory-change-count 10000
```

可以使用 `--output ./sample.json` 保存单次原始样本。相同规模的输入字节和 SHA-256 必须稳定；
耗时与内存是环境观测值，复测时应保留环境、工具版本和测量口径。

## 冻结预算

基线检查点之后在相同环境进行了两次独立最大档复测，观测总耗时分别为 `17.893218` 秒和
`17.891267` 秒，峰值追踪内存分别为 `328088984` 字节和 `328091338` 字节，固定输入哈希、
变化数、发现数、退出码和报告大小均保持一致。

预算 `1.0` 以初始基线 `17.948170` 秒和 `328089021` 字节为比较点，按工作项允许的百分之
二十回退冻结以下绝对上限：

| 指标 | 冻结上限 |
|---|---:|
| 端到端总耗时 | 21.537804 秒 |
| 峰值追踪内存 | 393,706,825 字节 |
| JSON 报告大小 | 4,889,503 字节 |
| 治理发现 | 0 项 |

以下命令会同时校验参考环境、规模、固定输入哈希、绝对性能上限、结果计数和退出码；预算违反
时返回退出码二，预算文件无效时返回退出码一：

```text
taiyi analyze benchmark --budget ./docs/质量/Agent记忆分析性能预算_v1.json
```

预算只适用于本文记录的固定参考环境。其他机器可以采样，但环境不匹配不会被误报为参考环境
预算通过。冻结后，同规模耗时或内存未经说明不得回退超过百分之二十；调整基线或阈值必须
提升预算版本并记录原因和复测证据。
