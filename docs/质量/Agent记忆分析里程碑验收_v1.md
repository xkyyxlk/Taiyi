## 功能验收

| 范围 | 结论 |
|---|---|
| 产品与架构边界 | 新方向、用户、首个场景、非目标、只读旁路和新旧数据隔离已进入产品与架构文档 |
| 协议与兼容 | JSONL 协议 `1.0`、严格校验、版本策略、顺序、引用和哈希规则已实现 |
| 差异与规则 | 新增、删除、内容与结构变化，以及来源、作用域和两类审计链规则均有固定测试 |
