## 目标

- 将已经验证的命令行工程闭环转化为十至十五分钟可体验的本地交互式产品原型。
- 保护来源、隔离、人工审核、快照不可变、陈旧提案和回滚不变量。
- 提供默认离线、无需 API 密钥的开箱即用演示场景。

## 本次完成内容

- 新增 `taiyi prototype` 命令，默认启动只监听 `127.0.0.1` 的本地产品原型；
- 新增产品原型状态投影和内部 JSON 操作，全部复用既有应用服务；
- 实现身份创建、两个同位体派生、隔离世界线经历和候选记忆展示；
- 实现从记忆下钻到来源事件、正文哈希、提取器和可信度；
- 实现重复、补充和冲突比较，以及五种人工归一策略；
- 保持审核与应用分离，未审核提案不能生成新快照；
- 显示陈旧提案并阻止它覆盖较新的当前快照；
- 实现不可变快照历史、当前指针回滚和从当前快照重生；
- 提供“未知任务的两种选择”离线演示预设和响应式步骤引导；
- 增加核心流程、陈旧提案、本地 HTTP、安全响应头和命令入口测试；
- 新增使用指南并更新产品定义、已知限制、开发计划、系统架构和变更日志；
- 新增架构决策 0005，记录本地 HTTP 界面和非公共协议边界。

## 重要决策

- 使用 Python 标准库 HTTP 服务和无构建步骤的静态页面，避免为早期原型引入第二套运行时；
- 服务地址固定为本机回环地址，不开放远程监听配置；
- 原型应用只调用现有应用服务，不直接写 SQLAlchemy 记录或改变领域语义；
- 内部 JSON 不承诺稳定性，不作为 SDK 或公共 API；
- 默认冲突仍采用悬置，演示只预填人工综合内容，不替用户自动批准；
- 本次不部署或托管页面，因为产品范围明确要求本地优先并排除生产级基础设施。
