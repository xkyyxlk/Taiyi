# 太一迭代记录索引

> 本目录是项目的永久迭代档案。已完成记录只追加、不删除、不覆写；如需纠错，应在原记录末尾追加更正说明。

## 记录规则

- 每次产生仓库改动的开发迭代都必须建立一份记录；纯讨论且没有形成仓库改动时可以不建档。
- 一个跨会话工作项可以有多份会话迭代记录，并在完成时增加一份工作项总结。
- 记录至少包含目标、完成内容、重要决策、验证结果、相关提交、影响范围和遗留事项。
- 新记录使用 `年-月-日-序号-主题.md` 命名，并在本索引末尾追加一行。
- 已完成记录不得为保持简洁而删除；版本变更日志不能替代本目录中的工程记录。
