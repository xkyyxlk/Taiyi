## 目标

- 提供协议校验和确定性分析的命令行入口；
- 支持版本化策略文件和稳定的持续集成退出码；
- 证明分析命令不会初始化或访问旧身份 SQLite。

## 本次完成内容

- 增加 `taiyi analyze validate`，校验 JSONL 并输出协议、项目、运行和记录数摘要；
- 增加 `taiyi analyze check`，运行差异和规则并输出完整 JSON 报告；
- 支持通过 `--policy` 读取策略 `1.0` 文件；
- 将文件、协议和策略错误映射为退出码一，策略通过映射为零，硬错误发现映射为二；
- 根命令识别分析子命令并跳过旧 `Settings`、数据库和仓储初始化；
- 报告增加参数数组形式的复现命令，包含输入和可选策略绝对路径；
- 更新 README 和规则报告规范，记录开发版本命令、边界和退出码；
- 增加命令通过、策略阻断、协议失败、策略降级、未知规则和不创建数据库的集成测试。

## 重要决策

- 分析命令继续存在于统一 `taiyi` 入口，但根回调必须在 `analyze` 子命令前返回；
- 复现命令使用参数数组，不生成依赖特定 Shell 转义规则的单字符串；
- 有效但被策略阻断的报告仍完整写入标准输出并返回二；
- 输入、协议和策略错误写入错误输出并返回一；
- 当前只输出 JSON，人类可读 Markdown/HTML 报告在下一检查点实现。
