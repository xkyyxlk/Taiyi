## 目标

- 冻结 LangGraph/LangSmith 首个参考版本和离线输入契约；
- 将 Store 前后快照、运行记录和显式写入来源转换为中性 JSONL 协议；
- 保持分析核心无框架依赖、默认离线和只读旁路边界。

## 本次完成内容

- 新增外围 `taiyi.adapters` 包，分析核心没有导入框架适配器；
- 冻结适配器契约 `1.0`、LangGraph `1.2.10` 和 LangSmith `0.10.11` 离线参考版本；
- 定义 Store 项目、checkpoint、LangSmith 运行和显式记忆写入的严格 Pydantic 模型；
- 实现重复字段、非有限 JSON、框架版本、引用、标识冲突、快照项目、旁车写入和内容哈希
  一致性校验；
- 将 checkpoint 映射为前后快照、Store 项目映射为记忆、运行和显式写入映射为事件；
- 规范化 JSON 后计算 SHA-256，转换结果不复制 Store 值或运行输入输出；
- 显式写入辅助函数生成稳定记忆 ID、作用域、类型、来源和写入器版本旁车记录，不调用
  `store.put` 或获得外部写权限；
- 新增 `taiyi analyze adapt-langgraph`，读取本地 JSON 并输出中性 JSONL；
- 增加离线输入与标准输出金夹具、确定性转换、缺失来源、不支持版本、哈希错配、辅助函数、
  无网络路径和命令行集成测试；
- 新增参考适配器架构说明，并更新 README、文档索引、协议、系统架构和产品当前状态。

## 重要决策

- 精确版本表示经过当前离线夹具验证；相邻版本不会被静默视为兼容；
- 太一运行依赖不增加 LangGraph 或 LangSmith，SDK 数据提取由用户 Agent 环境负责；
- 框架原生数据不能证明稳定记忆 ID、业务作用域、记忆类型或来源时，必须由显式写入旁车
  记录提供，不能按文本、时间或命名空间猜测；
- 记忆的 `source_event_ids` 直接使用 `source_run_ids`，不使用写入事件掩盖空来源；
- Store 值、运行输入和输出只进入本地规范化哈希，不复制到中性协议；
- 当前设计落实既有架构决策 0006，没有改变核心领域、协议或安全边界，因此不新增决策记录。
