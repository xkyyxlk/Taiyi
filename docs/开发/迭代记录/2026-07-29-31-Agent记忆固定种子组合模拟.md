## 目标

- 扩展差异、协议和审计链的手工审查机器夹具；
- 实现固定种子、跨进程稳定的提交级组合生成器；
- 提供生成、执行和复核一千个组合案例的命令行入口。

## 本次完成内容

- 将机器夹具从四个扩展到十四个，新增无变化、新增、删除、作用域变化、重复记忆标识、
  悬空来源、正文哈希不一致、不支持版本、父子时间倒置和事件循环场景；
- 所有有效机器夹具直接校验变化摘要、规则编号和退出码，所有无效夹具校验稳定错误片段；
- 新增固定种子组合生成器 `1.0`，覆盖记忆存在性、正文变化、来源缺失、作用域不一致和
  写入器变化；
- 使用 SHA-256 对种子、轮次和维度键排序，避免依赖 Python 随机哈希或进程状态；
- 标准答案从生成维度独立推导，再与分析器的变化摘要、规则编号和退出码比较；
- 新增 `taiyi analyze simulate`，按案例输出 JSONL，并写出包含版本、种子、维度、输入哈希、
  套件哈希和预期结果的 `manifest.json`；
- 增加一千案例零差异、同种子可复现、维度覆盖和命令行重复运行测试；
- 更新 README 和标准场景说明。

## 重要决策

- 提交级基线固定为一千个案例，默认种子为 `20260729`；
- 组合生成与验证路径不调用模型或网络，不初始化旧身份 SQLite；
- 生成器不调用被测分析器产生标准答案，以免测试与实现同源；
- 生成器 `1.0` 只承担第一阶段单记忆组合，多记忆、多来源、全部作用域与模型、提示词、
  工具版本组合留到里程碑级生成器；
- 自动组合案例扩大工程覆盖，但不能替代至少六十个经人工审查的金样本。
