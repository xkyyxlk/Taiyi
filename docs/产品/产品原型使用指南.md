# 太一产品原型使用指南

- 对应工作项：`TY-202607271741`
- 原型阶段：本地交互验证
- 适用用户：项目创建者和少量早期探索者

## 启动

完成开发安装后，使用全新的数据目录启动：

```bash
taiyi --data-dir .taiyi-prototype prototype
```

服务默认只监听 `127.0.0.1:8765` 并使用默认浏览器打开。需要指定端口或禁止自动打开时：

```bash
taiyi --data-dir .taiyi-prototype prototype --port 9000 --no-open
```

同一数据目录只能创建一个身份核心。需要重新体验时，请使用另一个全新目录；不要为了
重置演示而删除仍需保留的真实数据。

## 十至十五分钟演示

页面默认预填“未知任务的两种选择”：

1. 创建身份核心“岔路旅人”及初始快照；
2. 从初始快照派生“探索者”和“守护者”；
3. 分别记录优先可逆探索和优先规避风险的经历；
4. 展开候选记忆，查看来源事件、世界线和正文哈希；
5. 比较两条世界线，确认系统识别同一主题下的冲突；
6. 将冲突从默认“悬置”改为“综合”，检查预填的人工综合内容；
7. 明确批准策略，再单独应用提案生成新快照；
8. 从新快照重生“协调者”，或在历史中回滚当前指针。

默认 `MockProvider` 完全离线、输出可重复，不需要 API 密钥。演示预设只负责预填内容，
不会跳过人工审核或自动修改身份。

## 页面如何表达身份边界

- **稳定身份层**展示身份核心和当前快照指针；
- **运行时经历层**展示同位体、隔离世界线、事件和候选记忆；
- **记忆来源**从候选内容下钻到原始事件，并保留提取器和可信度；
- **显式跨线操作**只在比较和归一区域发生；
- **可继承身份层**只展示已经经过审核并写入快照的内容；
- **回滚**只移动当前指针，不删除后来生成的快照；
- **重生**从当前快照启动新的同位体，不表示意识转移或主观复活。

## 安全与限制

- 原型只绑定本机回环地址，不提供远程访问、登录或多用户权限；
- 所有操作复用现有应用服务，未审核提案不能生成快照；
- 陈旧提案会被标记并阻止应用；
- 页面显示的模型输出和候选记忆仍是不可信派生数据；
- 本地 JSON 操作只供当前页面使用，不是稳定 SDK 或公共 API；
- 原型不能证明记忆客观真实，也不能证明 AI 具有主观意识。

## 反馈重点

早期试用首先记录以下问题，不提前扩展产品范围：

- 用户能否区分身份核心、同位体、世界线、候选记忆和快照；
- 用户能否理解为何查看来源先于人工归一；
- 五种处理策略中哪些名称或结果最难理解；
- 回滚和重生是否容易被误解为删除或意识转移；
- 哪一步最能体现人工控制身份继承的价值；
- 哪些页面或信息可以删减，而不是继续增加功能。
