# 太一产品定义

- 文档状态：新方向已确定，首个里程碑开发中
- 对应工作项：`TY-202607281622`
- 外部议题：[GitHub #5](https://github.com/xkyyxlk/Taiyi/issues/5)
- 当前发布基线：`v0.1.1` 身份演化产品原型
- 更新时间：2026-07-29

## 一句话定义

太一是一个本地优先、只读旁路的 Agent 长期记忆分析与变更治理工具。它比较 Agent 运行
前后的记忆快照，追踪变化来源和作用域，生成可复现的风险证据，并通过稳定规则帮助开发者
在命令行和持续集成中发现记忆污染、串线和审计链断裂。

## 当前阶段与证据边界

项目已经发布 `v0.1.1` 身份演化产品原型，验证了隔离世界线、来源追踪、人工审核、不可变
快照和回滚的工程闭环。该版本没有获得真实用户证据，不能证明“AI 身份版本控制系统”是
成立的独立产品方向。

`TY-202607281622` 将下一阶段收敛为 Agent 长期记忆分析与变更治理。当前已完成协议、
确定性分析、持续集成策略、提交级模拟、畸形输入、六十个金样本、首个离线参考适配器和
固定环境性能基线，里程碑组合规模与性能预算仍在开发中。因此：

- 本文定义的是正在建设的产品方向和首个里程碑边界；
- 当前可安装版本仍只提供 `v0.1.1` 身份演化能力；
- 文档不得把规划中的分析能力表述为已经发布；
- 模拟实验只证明工程正确性，不构成采用价值、市场需求或真实项目效果证据。

## 要解决的问题

长期运行的 Agent 会从对话、网页、文档和工具结果中持续形成记忆。模型、提示词、工具、
提取器或输入资料发生变化后，开发者通常难以回答：

- 哪些记忆新增、修改或删除，变化是否符合预期；
- 一项记忆由哪些原始事件和写入器版本产生；
- 用户、Agent 或租户作用域是否发生串线；
- 来源缺失、记录乱序或审计链断裂是否污染后续状态；
- 同一基线在不同实验运行中为何产生不同记忆结果；
- 哪些确定性错误应阻断持续集成，哪些不确定风险只应告警；
- 出现污染后应向外部系统提供哪些证据以支持人工恢复。

太一不替换 Agent 和记忆库，而是把这些不可见的运行副作用转化为可以比较、追踪、验证和
治理的工程状态。

## 首批用户与核心任务

首批用户是正在调试长期记忆、记忆漂移、来源和作用域问题的 Agent 开发者与研究型
开发者。他们能够提供运行记录和记忆快照，接受早期协议演进，并需要在本地或持续集成中
得到稳定、可解释的结果。

他们的核心任务是：修改模型、提示词、工具、提取器或输入资料后，对同一 Agent 基线执行
两个或多个实验运行；随后使用太一比较记忆变化、校验来源和作用域、检查策略，并决定是否
在原系统中晋升、修复或恢复记忆。

当前不把普通消费者、企业级多用户团队或只需要通用 Agent 编排和运行追踪的团队作为首批
用户。

## 产品形态

首个里程碑以命令行和持续集成为主，不建设新的交互式网页产品：

```text
Agent 或适配器 -> 版本化 JSONL -> 太一只读分析 -> JSON 与人类可读报告 -> 人工或 CI 决策
```

- 框架无关 JSONL 是稳定输入边界；
- LangGraph/LangSmith 只作为首个参考适配器，不反向约束分析核心；
- 默认执行路径完全离线，不调用外部模型或服务；
- 分析结果包含规则编号、证据、输入哈希、工具版本、策略版本和复现命令；
- 太一只报告问题，不自动写入、删除、晋升或回滚外部记忆。

## 中性领域模型

新分析模块使用以下用户可见对象，不以“身份核心、同位体、世界线、归一、重生”表达
Agent 记忆分析：

| 对象 | 含义 |
|---|---|
| `AgentProject` | 被分析的 Agent 项目及其稳定标识 |
| `Run` | 一次执行或实验运行及其版本化环境 |
| `MemorySnapshot` | 运行前后某一时刻的记忆状态 |
| `MemoryChange` | 记忆新增、修改、删除或结构变化 |
| `Evidence` | 支持变化判断的输入、工具结果和来源事件 |
| `Finding` | 来源、作用域、审计或漂移规则产生的发现 |
| `Policy` | 规则严重级别、升级方式和持续集成行为 |
| `AnalysisReport` | 结构化结果和面向人的可复现报告 |

这些对象属于新的分析领域，不复用 `v0.1.1` 的身份领域对象或数据库主键。

## 标准产品场景

1. 开发者选择一个 Agent 基线，并记录模型、提示词、工具和写入器版本；
2. 适配器导出运行前记忆快照、运行事件、来源关系和运行后记忆快照；
3. 太一校验协议版本、记录结构、稳定标识、顺序和引用完整性；
4. 太一标准化两个或多个运行，比较记忆新增、修改、删除和结构漂移；
5. 确定性规则检查来源缺失、作用域串线和审计链断裂；
6. 版本化策略把发现映射为硬错误、默认告警或用户显式升级；
7. 太一输出 JSON 和 Markdown/HTML 报告及稳定退出码；
8. 开发者依据证据在原 Agent 系统中决定是否晋升、修复或恢复记忆；
9. 相同输入、工具版本和策略版本可以复现相同分析结果。

## 产品承诺与安全边界

首个里程碑必须保证：

- 输入协议和分析报告具有明确版本及兼容策略；
- 稳定记忆标识、作用域和显式来源的缺失会明确失败或降级；
- 确定性分析对相同输入产生相同结果；
- 所有阻断都提供规则编号、证据和复现方法；
- 默认路径不产生网络调用，不把原始轨迹或记忆上传到外部服务；
- 分析过程不获取外部记忆库的写权限；
- 报告明确区分事实性结构错误与未经证明的语义风险；
- 旧身份演化数据库不被读取、迁移或修改。

太一不承诺：

- 自动判断一项记忆在客观世界中为真或为假；
- 自动判断内容是否恶意、过期或应当删除；
- 来源完整就代表行为一定安全或稳定；
- 模拟结果等同于真实项目价值或采用意愿；
- 首个里程碑提供托管服务、多用户权限或生产服务等级；
- 当前未冻结的协议、规则和适配器已经达到长期兼容状态。

语义风险默认只能告警。只有用户通过版本化策略显式升级后，相关规则才能产生阻断；模型
输出本身不能成为无法解释的阻断依据。

## 首个里程碑范围

- 框架无关的版本化 JSONL 输入与报告协议；
- 输入校验、运行和快照标准化；
- 记忆新增、修改、删除和结构漂移比较；
- 来源完整性、作用域隔离和审计链规则；
- 分级策略、规则编号和稳定持续集成退出码；
- JSON、Markdown/HTML 报告；
- LangGraph/LangSmith 参考适配器及必要的显式写入埋点；
- 带标准答案、固定种子和版本化元数据的分层模拟套件；
- 默认完全离线的执行路径和性能基线。

首个里程碑不包含大模型语义冲突裁决、事实过期判断、攻击意图识别、外部记忆写入、通用
Agent 编排、新网页产品、托管云服务或多用户权限。

## `v0.1.1` 兼容模块

现有身份演化原型继续作为已发布兼容模块维护。它保留身份核心、同位体、世界线、候选
记忆、人工归一、不可变快照、回滚、重生、擦除和本地产品原型界面，不迁移到新分析领域。

兼容边界如下：

- 旧 SQLite 数据库和现有命令保持原有语义；
- 新分析模块使用独立领域模型、协议入口和存储或输出目录；
- 不把旧数据库直接升级为 Agent 记忆协议；
- 不让新分析规则改变旧模块的人工审核和身份继承不变量；
- 兼容修复可以继续进行，但旧模块不再决定新产品的默认概念和长期架构。

## 进入真实项目验证的条件

协议、规则、报告和模拟规模达到工作项量化验收标准后，项目才能为真实 Agent 项目验证
建立独立工作项。真实验证应检查接入成本、报告可理解性、发现的实际价值和误报成本，不得
由模拟通过自动推导为产品方向已经得到验证。
