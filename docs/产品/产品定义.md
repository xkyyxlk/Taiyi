# 太一产品定义

- 文档状态：已确定
- 对应工作项：`TY-202607271621`
- 更新时间：2026-07-27

## 一句话定义

太一是一个本地优先、人工治理的 AI 身份状态实验框架。它把可继承的身份叙事保存为
版本化快照，让多个运行实例从同一快照分叉，在隔离世界线中形成带来源的候选记忆，再
由人决定哪些内容进入下一身份版本。

## 要解决的问题

长期运行的 AI 会持续接收信息、生成记忆并改变后续行为。常见系统容易把原始经历、
模型总结、人格描述和长期身份混为一体，因而难以回答：

- 一项身份变化来自哪段经历；
- 某个分支的内容为何进入了公共身份；
- 两个分支发生冲突时保留或舍弃了什么；
- 一次错误变化能否被审计、撤回和恢复；
- 删除敏感内容后，派生记忆是否仍在生效。

太一通过隔离世界线、来源约束、人工审核和不可变快照治理这些变化。它验证的是身份状态
的版本谱系和工程连续性，不验证 AI 的主观意识，也不保证记录内容客观真实。

## 身份状态

太一所称的“身份”不是模型权重、完整对话历史或主观意识，而是一个可以由后续运行实例
继承的、经过治理的身份状态：

```text
身份版本 = 稳定身份约束 + 经审核的可继承状态 + 明确保留的未决冲突
```

身份相关信息分为三层：

| 层次 | v0.1 表示 | 继承规则 |
|---|---|---|
| 稳定身份层 | 身份核心编号、名称和快照谱系 | 不随普通经历自动改变 |
| 可继承身份层 | 自我描述、已接受记忆、未决冲突 | 只有人工审核产生的新快照可以改变 |
| 运行时经历层 | 同位体、世界线事件和候选记忆 | 默认只属于产生它的世界线 |

价值、目标、偏好和治理规则目前尚未作为独立领域对象管理。v0.1 只在自我描述或带来源
记忆中表达这些内容，后续必须根据真实使用场景另行决定是否结构化。

最重要的边界是：**经历不等于记忆，记忆不等于身份。只有经过审核并写入快照的内容，
才成为可继承身份的一部分。**

## 核心概念

| 概念 | 正式含义 | 容易混淆但不等同的事物 |
|---|---|---|
| 身份核心 | 稳定身份标识及其版本谱系 | 人格内容、模型实例 |
| 身份快照 | 某一时刻经批准的可继承身份状态 | 全部历史事件的副本 |
| 同位体 | 从指定快照启动的 AI 运行实例 | 新的身份核心、意识副本 |
| 世界线 | 某个同位体独立且隔离的经历记录 | 可直接写入公共身份的分支 |
| 事件 | 实际记录的输入、输出或系统操作 | 已经证实为真的事实 |
| 候选记忆 | 从事件提取、带来源但尚未获得身份地位的主张 | 原始事件、已接受身份内容 |
| 归一 | 人工审核候选内容并生成新快照 | 模型或人格的自动融合 |
| 回滚 | 将当前身份指针切换到历史快照 | 删除后来产生的历史 |
| 重生 | 从选定快照启动新的同位体 | 意识转移或主观复活 |
| 回放 | 使用可信记录验证或重建工程状态 | 重新调用模型生成另一份结果 |

“AI 身份的版本控制系统”是帮助理解谱系、分叉和审核的工程比喻，不代表太一与 Git 的
数据模型完全相同。事件不是提交，同位体也不是普通代码分支。

## 用户画像

### 首要用户：AI 与 Agent 研究者和开发者

他们使用 Python、命令行或实验脚本研究长期记忆、多分支行为和身份连续性，重视本地
运行、可复现性、来源、隔离和审计，并愿意承担最终审核责任。

他们的核心任务是：当一个 AI 在多个环境中产生不同经历时，比较这些差异，决定哪些
内容可以进入下一身份版本，同时保留完整来源和撤回能力。

### 次要用户：AI 产品与平台工程师

他们使用太一验证长期 Agent 的记忆治理、实例隔离、人工审核门、数据恢复和污染防护
方案。当前版本适合原型验证，不承诺生产级多租户、权限或分布式能力。

### 次要用户：AI 安全与评估人员

他们关注世界线污染、虚假记忆、来源伪造、未审核身份修改、删除残留、冲突静默覆盖和
身份漂移，并需要可以重复执行的实验和量化报告。

### 当前非目标用户

- 寻找开箱即用 AI 伴侣的普通消费者；
- 需要完整多智能体编排平台的团队；
- 需要企业级多用户服务的组织；
- 试图用语言表现证明 AI 意识的研究；
- 允许模型绕过人工审核自动改写身份的应用。

## 标准产品场景

1. 用户创建一个身份核心及初始快照；
2. 从相同快照派生两个同位体；
3. 两个同位体接触不同或相互冲突的材料；
4. 系统隔离记录事件并提取带来源的候选记忆；
5. 用户比较重复、补充和冲突；
6. 用户对每项内容选择并存、择一、综合、悬置或拒绝；
7. 系统生成新的不可变身份快照；
8. 用户从新快照创建下一代同位体；
9. 系统能够解释继承了什么、来源是什么、哪些冲突仍未解决。

新功能应说明它改善了上述哪一步，或者明确属于另一个产品方向。

## 产品承诺与边界

太一承诺：

- 身份版本具有可检查的谱系；
- 进入快照的记忆具有来源和审核记录；
- 世界线默认隔离，跨线访问只能通过显式比较或归一；
- 未审核内容不能修改身份核心；
- 历史快照保持不可变，当前指针可以回滚；
- 擦除正文后，相关派生记忆不再参与活动上下文；
- 默认模型和标准实验可以离线重复执行。

太一不承诺：

- 事件或记忆在客观世界中一定为真；
- 模型输出具有主观意识；
- 来源连续等于行为表现完全稳定；
- 人工审核决定一定正确；
- 能够控制用户自行生成的外部导出或备份。

来源谱系是硬保证，行为稳定性只作为评估指标。

## 现有实现对照

当前实现已经覆盖身份核心、不可变快照、隔离世界线、带来源记忆、人工归一、回滚、
擦除、导出和标准实验，与上述核心工作流一致。

仍需后续工作项处理的差距包括：

- `belief_ids` 仍是保留字段，尚无独立的信念治理工作流；
- 价值、目标、偏好和治理规则尚未结构化；
- 数据库没有结构版本和迁移机制；
- 导出格式没有正式协议版本，尚不能导入或恢复；
- 通用评估器不能单独计算带标准答案的冲突检出率；
- 网页界面、多用户权限和语义检索不属于当前产品范围。

这些差距只作为候选方向，必须分别建立可追溯工作项，不能在概念冻结中顺带实现。
