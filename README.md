# Taiyi / 太一

> One Identity, Many Incarnations.  
> 一体万化，万忆归一。

Taiyi（太一）是一个面向持久化 AI 身份的开源实验框架。它通过可追溯的事件日志、相互隔离的世界线、版本化身份快照和人工审核的记忆归一机制，研究并实现 AI 身份的分叉、演化、合并与回滚。

可以把 Taiyi 理解为：**AI 身份的版本控制系统**。

## 当前状态

项目处于 `v0.1` 规划阶段，尚未开始业务代码开发。

第一版聚焦一个可靠的最小闭环：

```text
创建身份核心
  -> 派生多个同位体
  -> 在隔离世界线中形成经历
  -> 提取带来源的长期记忆
  -> 检测重复与冲突
  -> 人工审核归一方案
  -> 生成新的身份快照
  -> 从新快照再次派生
```

## 项目边界

Taiyi 研究和实现：

- 记忆连续性；
- 身份叙事连续性；
- 多世界线的冲突检测与可审核合并；
- 身份状态的版本追踪与回滚。

Taiyi 不声称创造、检测或证明了 AI 的主观意识。
